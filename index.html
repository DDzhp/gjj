方案 A · DocScanner 算法（移植自 Nat30/nat30.github.io 的 cv-engine.js）： 灰度化 → 光照均衡 → 均值自适应阈值 adaptiveThreshold(MEAN_C) → 3×3 多数表决去噪。 纯 Canvas 实现，零依赖、完全离线可用，不改变原图构图，适合已经拍正的文档。

方案 B · jscanify 算法（复刻自 jscanify v1.4.0 的 findPaperContour / getCornerPoints / extractPaper）： Canny(50,200) → 高斯模糊 → OTSU 阈值 → 最大轮廓 → 四象限取角点 → 透视变换拉正 → 高斯自适应阈值 adaptiveThreshold(GAUSSIAN_C)。 会自动裁掉桌面背景并把倾斜的纸张拉正，依赖 OpenCV.js（约 9MB，首次需联网）。

调参建议：字迹发虚就调低 C；背景出现灰色麻点就调高 C 或加大噪点清理； 细小文字粘连成块时把阈值窗口调小。点击任意预览图可查看大图对比。
